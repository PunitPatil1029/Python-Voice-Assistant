# Python Voice Assistant

A beginner-friendly Python voice assistant project.

## Features
- Voice recognition using SpeechRecognition
- Text-to-speech using pyttsx3
- Responds to greetings
- Tells the current date and time
- Searches the web using voice commands

## Technologies Used
- Python
- SpeechRecognition
- pyttsx3
- datetime
- webbrowser

## Project Status
Currently under development.
